☆ Change gamma, brightness, and contrast. (Old programs used to change brightness automatically when you set gamma too high - this program only changes the gamma when adjusting gamma settings.)

☆ Save and load profiles. They are stored in a config file, so you can easily import someone else's config.

☆ Choose which monitor you want to adjust. (Old gamma tools only worked on a single display.)

☆ If you close or minimize the app, it will stay in the system tray (hidden icons).

☆ Calculate recommended settings using interpolation.

☆ Bind global hotkeys for multiple actions:
  - Increase/decrease Gamma, Brightness, and Contrast by the set value
  - Refresh current settings
  - Reset all values to default
  - Load up to 7 custom config profiles instantly via binds

☆ Lock specific hotkeys and parameter steps to prevent accidental modifications.

☆ Extra features in the Addons tab:
  - Enable custom .png overlay with adjustable frame settings (Outline width, Softness fade, Black opacity).
  - Automatically apply a specific default configuration on startup (and when using the reset bind).
  - Reset all settings to default automatically upon closing the application.

☆ Antivirus software might falsely detect a trojan due to gdi32.dll - that's just a Windows thing for changing gamma.

☆ If you want to run the application automatically on Windows startup:
  1. Go to the folder containing the application's .exe file.
  2. Right-click the .exe file and select "Create shortcut" (or simply Copy it).
  3. Press Win + R on your keyboard, type "shell:startup", and press Enter.
  4. Move or Paste the shortcut into the Startup folder that just opened.
